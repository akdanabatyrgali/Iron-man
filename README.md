#Iron Man Suit Management System
Team Members
1.Akdana Batyrgali: Factory Method, Observer, State.
2.Azhar: Strategy, Command, Facade.

This is a Java console application inspired by Marvel's Iron Man. Users can select suits, choose weapons, complete missions, attack enemies, and manage energy and armor.

Design Patterns:

Factory Method — creates different suits.
Observer — monitors energy and armor.
State — controls suit states.
Strategy — selects weapons.
Command — executes actions.
Facade — connects all systems.
Technologies:
Java 17, IntelliJ IDEA, Maven, JUnit 5.
